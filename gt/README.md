# GT (Giffler-Thompson) Algorithmus

Dieses Verzeichnis enthält Skripte für den **GT-Algorithmus**.

##  Experimente ausführen

```bash
python gt/run_experiments.py
```

---

##  Weitere Informationen

**Kern-Implementation:**
- `src/solvers/GT_Scheduler.py` - GT-Algorithmus
- `src/GT_Experiment_Runner.py` - Experiment-Runner

Der GT-Algorithmus ist ein heuristischer Ansatz für Job-Shop Scheduling.
